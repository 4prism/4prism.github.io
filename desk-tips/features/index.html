데스크알리미 › 기능 소개

주요 기능

데스크알리미가 치과 데스크 업무를 어떻게 바꾸는지 기능별로 살펴보세요.

서류 자동화

보험서류 5종 한 번에

실비·치아보험에 필요한 모든 서류를 버튼 하나로 만드는 기능.

 리콜 자동화

리콜 전화 명단 + 첫마디

오늘 전화할 환자 목록과 어떤 말로 시작할지 알려주는 리콜 기능.

 부재중 관리

부재중 전화 자동 감지

치과 대표 번호로 걸려 온 부재중 전화를 자동으로 감지해서 콜백 목록을 만들어 주는 기능.

 일정 관리

지각 환자 사전 알림

예약 시간에 늦을 가능성이 있는 환자를 미리 파악해서 진료 순서 조정에 활용하는 기능.

 수술 준비

수술 환자 콜 체크리스트

임플란트·발치 등 수술 전 콜이 필요한 환자를 자동으로 목록에 올려주는 기능.

 빈자리 대응

빈자리 채우기

당일 취소 발생 시 빠르게 연락할 수 있는 대기 환자 목록을 자동으로 보여주는 기능.

 성과 관리

리콜 결과 차트 자동 기록

리콜 전화 결과를 카드에서 클릭만으로 기록하고, 월별 성과 차트로 확인하는 기능.

 통합

덴트웹 위에서 그대로

덴트웹 화면을 바꾸지 않고 그 위에서 동작합니다. 기존 사용 방식을 유지하면서 추가 기능만 씁니다.

 설치

1~2분 설치, 교육 불필요

Windows 데스크 PC에서 명령어 한 줄, 1~2분이면 설치가 끝납니다. 별도 교육이 필요 없습니다.

 멀티 PC

여러 PC에서 동시 사용

원무·데스크·진료 보조 등 여러 PC에 설치해서 같은 정보를 공유하는 방법.
