0. 수가코드별 청구 목록 — 이 리포트의 바탕

진료군(§4)이 아니라 수가코드 단위로 쌓은 구성비다. 상위 코드만 색을 주고 나머지는 「기타」로 묶었다. 막대 높이를 100%로 맞춰 구성비 변화를 보고, 토글로 실수(實數) 누적으로 바꿔 규모도 볼 수 있다.

신규 등장 · 사용 중단 코드 — 코드 교체를 잡는다

이상치 판정은 "늘 쓰던 코드가 흔들렸나"를 본다. 그런데 코드가 통째로 바뀌는 일도 있다 — 이건 z 로 안 잡히고(기준선 자체가 없다) 군 합계로도 안 보인다(총량은 유지되므로). 그래서 선택 구간에 처음 등장한 코드와 쓰이다 멈춘 코드를 따로 세운다.

2. 청구 흐름 변화 — 코드 구성이 과거와 얼마나 다른가

총량이 같아도 무엇을 청구하는지가 바뀌면 진료 양상이 달라진 것이다. 지표는 이동률 — 과거 구성을 지금 구성으로 바꾸려면 청구의 몇 %를 다른 코드로 옮겨야 하는지다(총변동거리 TVD). 0% = 구성이 똑같음, 클수록 흐름이 바뀐 것. 총량 증감과 무관하게 구성만 본다.

짧게 잡으면 최근 변화에, 길게 잡으면 구조적 변화에 민감하다.

6. 진료군 이상치 — 어느 달이 얼마나 튀었나

§1 과 같은 판정식을 진료군 단위로 적용한 것이다. 로버스트 z = (해당월 − 중앙값) / (1.4826 × MAD) — MAD(중앙절대편차)는 평균·표준편차와 달리 튀는 달 자체에 끌려가지 않는다. |z| ≥ 3.5 심각 · 2.5 주의 · 1.8 관찰. 표본 6개월 미만이거나 월 중앙값이 너무 작은 저빈도 군, 그리고 미완월(*) 은 판정하지 않는다. 🔴 군 안에서 코드끼리 상쇄되면 여기서는 안 보이니 §1 과 함께 봐야 한다.
